# Evaluation output

Produced by `train_model.py` on every run.

| File | Contents |
|------|----------|
| `confusion_matrix.png` | Which classes get mistaken for which |
| `training_curves.png` | Accuracy and loss per epoch, both phases |
| `results.json` | All metrics as structured data |

Interpretation of these results is in [`../../docs/model-card.md`](../../docs/model-card.md).
